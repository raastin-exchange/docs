# احراز هویت

API صرافی <ExchangeName /> برای دسترسی به اندپوینت‌های خصوصی (همه‌ی اندپوینت‌های زیر `/api/v2/` به‌جز `/time` و `/exchangeInfo`) از **JWT Bearer** استفاده می‌کند.

## فرمت هدر

<div dir='ltr'>

```http
Authorization: Bearer <JWT_TOKEN>
```

</div>

## دریافت توکن

برای دریافت JWT با مراجعه به پنل کاربری خود در <ExchangeName /> از بخش حساب کاربری وارد صفحه مدیریت API شده و توکن خود را دریافت نمایید.

:::caution نکته‌ی امنیتی
توکن JWT را در کد منبع عمومی، لاگ‌ها، یا فایل‌های مشترک قرار ندهید. توکن خود را به‌صورت متغیر محیطی (environment variable) نگهداری کنید.
:::

## اندپوینت‌های عمومی

دو اندپوینت بدون نیاز به احراز هویت در دسترس‌اند:

- `GET /api/v2/time` — همگام‌سازی ساعت (`{ "serverTime": <ms> }`).
- `GET /api/v2/exchangeInfo` — متادیتای نمادها (tick size، step size، حداقل سفارش، …).

سایر اندپوینت‌ها نیازمند توکن معتبر هستند.

## پاسخ خطای احراز هویت

اگر توکن نامعتبر، منقضی، یا غایب باشد، سرور با کد HTTP 401 و پوشش خطای زیر پاسخ می‌دهد:

```json
{
  "code": -2014,
  "message": "Invalid auth or JWT"
}
```
