# پوزیشن‌های مارجین

## GET /api/v2/positions

لیست پوزیشن‌های کاربر با cursor pagination.

### پارامترهای کوئری

| نام | نوع | توضیح |
| --- | --- | --- |
| `symbol` | String | محدودسازی به یک نماد (مانند `BTCUSDT`). |
| `status` | String | `open` (پیش‌فرض)، `closed`، `terminating`. |
| `source` | String | `orderbook`، `otc`، `strategy`. |
| `fromId`، `limit` | — | استاندارد cursor pagination. |

## GET /api/v2/positions/{`positionId`}

دریافت یک پوزیشن خاص با شناسه‌ی عددی آن.

## POST /api/v2/positions/{`positionId`}/close

بستن سریع کامل پوزیشن (fast-close). معادل سفارش بازار با `isOpenPosition=false` و قیمت بازار.

```mdx-code-block
<Tabs defaultValue="response" values={[{label:'پاسخ', value:'response'}]}>
<TabItem value="response">
```

```json
{
  "positionId": "8821",
  "status": "CLOSING"
}
```

```mdx-code-block
</TabItem>
</Tabs>
```

پس از این فراخوانی، وضعیت پوزیشن چند ثانیه بعد به `closed` خواهد رفت (پس از پر شدن fast-close order توسط موتور).
