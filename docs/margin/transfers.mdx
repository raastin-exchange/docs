# انتقال بین کیف‌پول‌ها

اندپوینت‌های انتقال بین کیف‌پول‌های اسپات، مارجین و پوزیشن.

## GET /api/v2/margin/transfers

تاریخچه‌ی انتقال‌های کاربر، با cursor pagination.

### پارامترهای کوئری

| نام | نوع | توضیح |
| --- | --- | --- |
| `type` | String | `SPOT_TO_MARGIN`، `MARGIN_TO_SPOT`، `MARGIN_TO_POSITION`، `POSITION_TO_MARGIN`. |
| `fromId`، `limit` | — | استاندارد cursor pagination. |

## POST /api/v2/margin/transfers

ایجاد یک انتقال جدید. نوع‌های `*_POSITION` نیازمند `symbol` و `positionId` هستند.

### بدنه درخواست

| نام | نوع | اجباری | توضیح |
| --- | --- | --- | --- |
| `type` | String | ✓ | یکی از مقادیر زیر. |
| `asset` | String | ✓ | نماد دارایی (مانند `USDT`، `IRT`). |
| `amount` | String | ✓ | مقدار به همان واحد دارایی. |
| `symbol` | String | شرطی | برای انتقال‌های مارجین ↔ پوزیشن. |
| `positionId` | int64 | شرطی | برای انتقال‌های مارجین ↔ پوزیشن. |

### نوع‌های پشتیبانی‌شده

| مقدار | معنا |
| --- | --- |
| `SPOT_TO_MARGIN` | اسپات → مارجین |
| `MARGIN_TO_SPOT` | مارجین → اسپات |
| `MARGIN_TO_POSITION` | مارجین → پوزیشن (افزایش collateral) |
| `POSITION_TO_MARGIN` | پوزیشن → مارجین (برداشت excess) |
