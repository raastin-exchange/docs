# موجودی حساب

<div dir="ltr" style={{textAlign: 'left'}}>

    GET /api/v2/account

</div>

موجودی هر دارایی را به تفکیک نوع کیف‌پول (SPOT، MARGIN، LOAN) برمی‌گرداند.

## پاسخ

```mdx-code-block

<TabItem value="response">
```

</TabItem>

### معنی فیلدها

| فیلد | معنا |
| --- | --- |
| `free` | موجودی قابل‌استفاده — معادل `balance - locked + credit`. |
| `locked` | بخش قفل‌شده برای سفارش‌های در حال انتظار. |
| `total` | کل موجودی (شامل اعتبارها). |
| `walletType` | نوع کیف‌پول: `SPOT`، `MARGIN`، یا `LOAN` (در آینده). |

:::info
این اندپوینت فقط موجودی‌های اصلی حساب کاربری را برمی‌گرداند.
:::
