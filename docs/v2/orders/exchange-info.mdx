# زمان سرور و متادیتای نمادها

این دو اندپوینت **عمومی** هستند و نیازی به احراز هویت ندارند.

## GET /api/v2/time

زمان فعلی سرور را به‌صورت میلی‌ثانیه یونیکس برمی‌گرداند. ربات‌ها در شروع اتصال آن را فراخوانی می‌کنند تا اختلاف ساعت محلی و سرور را تشخیص دهند.

```mdx-code-block
<Tabs defaultValue="response" values={[{label:'پاسخ', value:'response'}]}>
<TabItem value="response">
```

```json
{
  "serverTime": 1714560000000
}
```

```mdx-code-block
</TabItem>
</Tabs>
```

## GET /api/v2/exchangeInfo

فهرست تمام نمادهای فعال به همراه متادیتای موردنیاز برای محاسبه‌ی سفارش — `tickSize`، `stepSize`، حداقل/حداکثر مقدار، فعال‌بودن مارجین، حداکثر اهرم، و انواع سفارش پشتیبانی‌شده.

### پارامترهای کوئری

| نام | نوع | اجباری | توضیح |
| --- | --- | --- | --- |
| `symbol` | String | ✗ | اگر تنظیم شود، فقط همان نماد برگردانده می‌شود. |

```mdx-code-block
<Tabs defaultValue="response" values={[{label:'پاسخ', value:'response'}]}>
<TabItem value="response">
```
