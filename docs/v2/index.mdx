# API v2 — سطح سازگار با ربات‌ها

نسخه دوم API <ExchangeName /> یک سطح REST تمیز و سازگار با ربات‌های معامله‌گر (مانند Hummingbot، Freqtrade و کتابخانه‌های اختصاصی) است. این نسخه با الگوهای رایج صنعت طراحی شده تا ربات‌ها بدون نیاز به سفارشی‌سازی سنگین به آن متصل شوند.

## نکات کلیدی

| موضوع | مقدار |
| --- | --- |
| پایه آدرس | `/api/v2/` |
| فرمت نماد | `BTCUSDT`، `ETHIRT` (بدون جداکننده). فرم‌های `BTC/IRT` و `BTC-IRT` هم پذیرفته می‌شوند. |
| ساختار سفارش | تک خانواده `/orders` با فیلد `marketType` (مقدار `SPOT` یا `MARGIN`). |
| صفحه‌بندی | مبتنی بر cursor: `fromId` + `limit`. پاسخ شامل `nextCursor` و `hasMore`. |
| سبک JSON | کلیدهای camelCase، enumها UPPERCASE، اعداد اعشاری به‌صورت رشته. |
| زمان | میلی‌ثانیه یونیکس (عدد صحیح). |
| احراز هویت | JWT Bearer. |
| خطاها | پوشش `{ code, message, field? }` با کدهای عددی پایدار. |

## مشخصات OpenAPI

اسکیمای کامل OpenAPI 3.1 این سطح به‌صورت فایل قابل دانلود در صفحه [مشخصات OpenAPI](./openapi) قرار دارد. هر ابزار سازگار با OpenAPI (مانند openapi-generator، Stoplight، Postman) می‌تواند کلاینت تایپ‌دار از روی آن بسازد.
