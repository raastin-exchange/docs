# معرفی

API صرافی <ExchangeName /> یک سطح REST مدرن و سازگار با اکوسیستم ربات‌های معاملاتی است. این مستندات مرجع رسمی شماست برای ساخت ربات‌های اختصاصی، اتصال به کلاینت‌هایی مانند Hummingbot و Freqtrade، و خودکارسازی استراتژی‌های معاملاتی.

طراحی API بر اساس کنوانسیون‌های آشنای Binance / KuCoin / OKX انجام شده تا کاربرانی که از این صرافی‌ها مهاجرت می‌کنند، با کمترین تغییر در اتصالات بتوانند به <ExchangeName /> متصل شوند.

## نکات کلیدی

| موضوع | مقدار |
| --- | --- |
| پایه آدرس | `/api/v2/` |
| فرمت نماد | `BTCUSDT`، `ETHIRT` (بدون جداکننده). فرم‌های `BTC/IRT` و `BTC-IRT` هم پذیرفته می‌شوند. |
| ساختار سفارش | تک خانواده `/orders` با فیلد `marketType` (مقدار `SPOT` یا `MARGIN`). |
| صفحه‌بندی | مبتنی بر cursor: `fromId` + `limit`. پاسخ شامل `nextCursor` و `hasMore`. |
| سبک JSON | کلیدهای camelCase، enumها UPPERCASE، اعداد اعشاری به‌صورت رشته. |
| زمان | میلی‌ثانیه‌ی Unix (عدد صحیح). |
| احراز هویت | JWT Bearer. |
| خطاها | پوشش `{ code, message, field? }` با کدهای عددی پایدار. |
