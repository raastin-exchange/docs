# معرفی

API صرافی <ExchangeName /> یک سطح REST مدرن و سازگار با اکوسیستم ربات‌های معاملاتی است. این مستندات مرجع رسمی شماست برای ساخت ربات‌های اختصاصی، اتصال به کلاینت‌هایی مانند Hummingbot و Freqtrade، و خودکارسازی استراتژی‌های معاملاتی.

طراحی API بر اساس کنوانسیون‌های آشنای Binance / KuCoin / OKX انجام شده تا کاربرانی که از این صرافی‌ها مهاجرت می‌کنند، با کمترین تغییر در اتصالات بتوانند به <ExchangeName /> متصل شوند.

## شروع

1. **[احراز هویت](../authentication)** — JWT Bearer در هدر `Authorization`.
2. **[قراردادها و قواعد](../v2/conventions)** — نام نمادها، فرمت اعداد و تاریخ، صفحه‌بندی، کدهای خطا.
3. **[ثبت سفارش](../v2/orders/place-order)** — اولین فراخوانی شما.

## ساختار مستندات

- **[v2/orders/](../v2/orders/place-order)** — سفارش‌گذاری اسپات و مارجین، ویرایش، لغو، عملیات گروهی، لیست‌ها، تاریخچه‌ی اجرا و موجودی.
- **[v2/margin/](../v2/margin/positions)** — مدیریت پوزیشن، اهرم، انتقال بین کیف پول مارجین و پوزیشن.
- **[OpenAPI 3.1](../v2/openapi)** — برای تولید کلاینت تایپ‌دار (Python، TypeScript، Go، …).

## ویژگی‌های کلیدی

- **نمادهای فشرده**: `BTCUSDT`، `ETHIRT` (و معادل‌های `BTC/IRT`).
- **enumهای UPPERCASE**: `BUY`، `SELL`، `LIMIT`، `MARKET`، `GTC`، `IOC`، `FOK`، `FILLED`، …
- **اعشار به‌صورت رشته**: بدون خطای ممیز شناور.
- **زمان به میلی‌ثانیه‌ی Unix**: عدد صحیح، مستقل از منطقه زمانی.
- **صفحه‌بندی cursor**: `fromId` + `limit` در همه‌ی لیست‌ها.
- **پاسخ خطای استاندارد**: `{ "code": <int>, "message": "...", "field": "..." }`.
- **عملیات گروهی**: حداکثر ۲۰ سفارش در یک فراخوانی برای ایجاد / ویرایش / لغو.
